КАК УСТАНОВИТЬ:   
  1. справа сверху (чуть выше файлов) есть зелёная кнопка "<> Code", нажимаете на неё и выбераете нижнюю опцию "Download ZIP".   
  2. Как только скачается, нажимаете правой кнопкой мыши и "извлекаете" содержимое.   
  3. Всё, дальше можете создать ярлык для .exe (правой кнопкой мыши по .exe и ищете 'создать ярлык', а если у вас Windows 11, то чтобы найти 'создать ярлык' нажмите 'Показать дополнительные параметры')  
  4. ярлык можете хранить где угодно, как и папку с приложением, однако ничего не удаляйте в самой папке (кроме README.md, его можете удалить)  



HOW TO INSTALL: 
 1. On the top right (just above the files), there is a green button "<> Code", click on it and select the bottom option "Download ZIP". 
 2. Once downloaded, right-click and "extract" the contents. 
 3. That's it, now you can create a shortcut for the .exe (right-click on the .exe and search for "create shortcut", or if you have Windows 11, click "Show additional options" to find "create shortcut") 
 4. You can store the shortcut anywhere, just like the app folder, but don't delete anything in the folder itself (except for README.md, which you can delete)
